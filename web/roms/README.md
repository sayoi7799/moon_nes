# Homebrew games bundled with the web demo

Unmodified release ROMs of two homebrew games by Sebastian Dine, both under
the zlib license. Their license texts are kept next to the ROMs, as the
license asks.

| File | Game | Source | Release | License |
|---|---|---|---|---|
| `openNES-Snake-1.0.9.nes` | Snake | <https://github.com/sebastiandine/openNES-Snake> | [v1.0.9](https://github.com/sebastiandine/openNES-Snake/releases/tag/v1.0.9) | zlib, `openNES-Snake-LICENSE.txt` |
| `openNES-Pong-1.0.1.nes` | Pong | <https://github.com/sebastiandine/openNES-Pong> | [v1.0.1](https://github.com/sebastiandine/openNES-Pong/releases/tag/v1.0.1) | zlib, `openNES-Pong-LICENSE.txt` |

Both are NROM-128 (mapper 0). The repositories' LICENSE files cover the whole
repository; their graphics and sound folders carry no separate license.
